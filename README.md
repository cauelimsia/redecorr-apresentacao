# RedeCORR · Apresentação CORE5®

Apresentação institucional web da RedeCORR: o ecossistema de crescimento para corretores de planos de saúde e a metodologia CORE5®.

**Ao vivo:** https://clsolucoesweb.github.io/redecorr-apresentacao/

## Navegação

- `←` `→` `Espaço` `PgUp` `PgDn` — trocar de slide
- `Home` / `End` — primeiro / último slide
- Swipe no celular, scroll do mouse, botões na tela
- Cada slide tem URL própria (`#5` abre direto o pilar Tecnologia)

## Stack

HTML + CSS + JS puro, GSAP para animações (com fallback sem animação e suporte a `prefers-reduced-motion`). Sem build: é só servir a pasta.

## Deploy

GitHub Pages servindo a branch `main` (raiz).
